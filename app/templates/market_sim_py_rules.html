Every item has a hidden fair value on a random walk. Nobody can see it while the run is live — your bot only sees the book in front of it. Your P&L is marked at fair value, so quoting silly prices to yourself does not manufacture profit.

Writing a strategy

Define on_tick(ctx). It runs once per tick and returns a list of orders. An on_start(ctx) function is optional and runs once before the first tick.

What you get in ctx

ctx["tick"]           # 0, 1, 2, … up to {{ total_ticks }}
ctx["seconds_left"]   # time remaining in the run
ctx["items"]          # ["WIDGET", "GADGET", "GIZMO", "DOODAD"]
ctx["limit"]          # {{ position_limit }}
ctx["market"][item]   # {"bid", "ask", "bid_qty", "ask_qty", "mid", "spread", "last"}
                      #   any price may be None if that side of the book is empty
ctx["position"][item] # your signed position, negative is short
ctx["open_orders"][item]  # {"buy": qty, "sell": qty} still resting
ctx["cash"]           # cash from your fills so far
ctx["pnl"]            # cash + position marked at fair value
ctx["memory"]         # a dict that survives between ticks — put your state here

What you return

{"item": "WIDGET", "side": "BUY", "price": 99.95, "qty": 10}   # resting limit order
{"item": "WIDGET", "side": "SELL", "qty": 10}                  # market order, remainder pulled
{"action": "cancel_all"}                                        # pull all your resting orders
{"action": "cancel_all", "item": "WIDGET"}                      # pull one item's orders

Orders rest until filled or cancelled, so most strategies open the tick with a cancel_all and re-quote. Up to 20 orders per tick.

The rules your code runs under

  • Position limit {{ position_limit }} per item, long or short. Resting orders count toward it — an order that could breach the limit if fully filled is rejected outright.
  • No imports. math, stats (mean, median, stdev, clamp) and random are already in scope.
  • No file, network or system access, no class, no eval, no ** (use pow(a, b)). It is a computation-only sandbox.
  • 80ms per tick. Blow the budget three times and you are disqualified; raise 25 errors and the same happens. print() goes to your own log on the run page.

The house bots

The Market Maker Bot quotes a three-deep ladder around a lagging, noisy estimate of fair value and leans its quotes against its own inventory — it is beatable, and finding where its estimate is stale is most of the game. The Flow Bot takes liquidity in the direction of the real mispricing, so passive quotes get adversely selected. Both respect the same {{ position_limit }} limit you do.
